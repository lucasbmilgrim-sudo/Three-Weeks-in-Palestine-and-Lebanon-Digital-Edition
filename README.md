The metadata I chose to describe the 25 selected pages provided specific visual data as well as other important information about the book, both in the pages selected and when extrapolated to other pages. First, I chose to mark whether or not the pages included text, as there are several pages that only provide art, and some that have both on the page. I also noted whether or not each page had an engraving or a diagram, and recorded what the images represented. This physical data could help classify pages based on the content of them, and what information they provided to a reader – visual, textual, or both. Additionally, I recorded the location of the page along the author’s journey. While the pages I selected were all in Jerusalem, this metadata could be used by an analyst to separate pages by their location in the Middle East. Next, I recorded the languages represented in the pages. For the most part, each page was in English, but there were several other languages used, usually when quoting others. Finally, I recorded the heading or title of each page, which for the most part was different each time. However, some pages repeated titles, which could allow those analyzing the book to sort based on themes or repeated themes. These pieces of information could allow for sorting of the pages of this book in several different ways, depending on the goals of the sorter.

The OCR process was interesting and educational, while also being quite frustrating at times. I used the Adobe software, which was very cool to watch operate and convert my image into a text-backed file as well; however, it made considerable amounts of mistakes. One frequent error was the lack of ability to pick up italics. My text used these frequently for other languages, as well as for emphasis at times. The OCR software was not able to notice these, and put the text in as normally formatted. Other languages also became a problem, especially when Greek was used, as Adobe seemed to be only programmed to recognize English characters. In terms of other errors, they occurred at a frustrating frequency. Letters like d were almost always copied in as “cl”, and there were several dozens of errors that needed to be corrected on each page. Other media, which were prints, aren’t a part of my text files. This assignment led me to appreciate the OCRing process, as I understand how useful it is, but now see the difficulty and challenges it can present. Furthermore, if I endured these challenges with only 25 pages, I cannot imagine what could arise when doing this for an entire book.
